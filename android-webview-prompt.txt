# طلب تطبيق أندرويد (WebView) متوافق مع إشعارات Supabase

**الموضوع:** طلب إنشاء تطبيق أندرويد WebView لمتجر "الوزير للبصريات" مع دعم إشعارات الويب.

**موجز المشروع:**
نريد تطبيق أندرويد (WebView) يعرض موقعنا الإلكتروني. الإشعارات ستتم إدارتها بالكامل من خلال الموقع (PWA) باستخدام Supabase، ولا نحتاج لدمج أي SDK خارجي مثل OneSignal أو Firebase في التطبيق الأصلي.

**المتطلبات التقنية:**

1.  **WebView:**
    *   تحميل الموقع: `[ضع رابط موقعك الكامل هنا]`
    *   ملء الشاشة، تفعيل JavaScript و DOM Storage.
    *   معالجة انقطاع الإنترنت (صفحة No Internet).

2.  **الإشعارات (Push Notifications) - هام جداً:**
    *   **لا تقم بدمج أي SDK خاص بالإشعارات** مثل Firebase Messaging (FCM) أو OneSignal في كود الأندرويد.
    *   الموقع الإلكتروني سيستخدم **Service Worker** و **Web Push API** القياسية لطلب الإذن من المستخدم وتسجيله.
    *   المطلوب من تطبيق الأندرويد هو **فقط دعم وتمكين Web Push API** داخل الـ WebView.

3.  **الأذونات:**
    *   طلب أذونات الكاميرا والميكروفون (للميزات الموجودة في الموقع).
    *   التطبيق يجب أن يسمح للموقع بطلب إذن الإشعارات من المستخدم.

4.  **المطلوب تسليمه:**
    *   ملف APK و AAB.
    *   السورس كود.

---

**ملحوظة للمبرمج:**
كل منطق الإشعارات (الاشتراك والإرسال) يتم عبر Supabase والموقع الإلكتروني. دورك هو التأكد من أن الـ WebView لا يعيق هذه الوظائف القياسية للويب.
